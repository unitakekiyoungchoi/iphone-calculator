# iPhone 스타일 계산기

브라우저에서 동작하는 **iOS 계산기** 스타일의 작은 정적 웹 프로젝트입니다.  
검은 배경, 둥근 버튼, 주황색 연산자(선택 시 흰/주황 반전), 넓은 `0` 버튼, iOS와 비슷한 계산 규칙(×÷가 +−보다 우선, `=` 반복, `%` / `±`, 9자리 제한, 천 단위 쉼표, 0으로 나누면 Error 등)을 그대로 구현했습니다.

평면 화면(`index.html`)과 **3D 기기**(`3d.html`) 두 가지로 쓸 수 있습니다. 계산은 둘 다 `calculator.js`를 그대로 사용합니다.

빌드 도구나 CDN 의존성은 없습니다. HTML 파일을 더블클릭하면 오프라인에서도 바로 열립니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 2D 계산기 페이지 |
| `styles.css` | 2D 화면 스타일 |
| `3d.html` | 3D 계산기 페이지 |
| `3d.css` | 3D 페이지의 안내·링크 스타일 |
| `3d.js` | 3D 장면, 기기, 버튼, 입력 |
| `calculator.js` | 계산 로직 (브라우저·Node 공용) |
| `app.js` | 2D 버튼·키보드·스와이프 UI 연결 |
| `test.js` | Node로 실행하는 자동 테스트 |
| `vendor/three.min.js` | 오프라인용 Three.js r152 (MIT) |
| `vendor/fonts/` | 화면용 Inter, 안내 문구용 Noto Sans KR 일부 |

## 사용 방법

1. 저장소를 클론하거나 파일을 받은 뒤
2. **`index.html`을 더블클릭**하거나, 브라우저로 해당 파일을 엽니다.

데스크톱에서는 휴대폰 프레임으로 보이고, 좁은 화면(모바일)에서는 전체 화면으로 채워집니다. 왼쪽 위의 **3D 모드**를 누르면 3D 페이지로 이동합니다.

## 3D 모드

`3d.html`을 열면 계산기가 둥근 모서리의 휴대폰 형태 기기로 장면 안에 나타납니다. 조명은 본체 가장자리와 유리에 맺히고, 바닥에는 그림자와 기기 아래쪽의 반사가 보입니다. 주황색 연산 키, 회색 기능 키, 넓은 `0` 키는 2D와 같은 배치입니다.

숫자와 결과는 기기 **화면**에 바로 갱신됩니다. 키를 누르면 버튼이 안쪽으로 들어가고, 손을 떼면 다시 올라옵니다. 선택된 연산자는 2D처럼 흰 바탕에 주황 기호로 바뀝니다.

### 3D에서 조작하기

| 동작 | 결과 |
|------|------|
| 빈 곳을 드래그 (마우스·터치) | 기기를 회전하고 기울임 |
| 마우스를 화면 위에서 움직임 | 커서 쪽으로 살짝 기울임 |
| 가만히 두기 | 천천히 떠 있고 살짝 흔들림 |
| 버튼 클릭 또는 탭 | 계산. 누르는 동안 키가 들어감 |
| 키보드 | 아래 표와 같음 (2D와 동일) |
| 빈 곳 더블 클릭 | 처음 각도로 되돌림 |

왼쪽 위의 **2D 모드**로 평면 계산기에 돌아갑니다. 넓은 화면과 좁은 화면(세로 휴대폰) 모두에서 기기가 화면에 맞게 잡히고, 터치로도 회전할 수 있습니다.

Three.js와 글꼴은 `vendor/`에 포함되어 있습니다. 네트워크 없이 `3d.html`을 더블클릭해도 됩니다.

### 키보드 지원

| 키 | 동작 |
|----|------|
| `0`–`9`, `.` | 숫자 입력 |
| `+` `-` `*` `/` | 연산 |
| `Enter` 또는 `=` | 결과 |
| `%` | 퍼센트 |
| `Backspace` | 한 자리 삭제 (2D에서는 디스플레이를 스와이프해도 같음) |
| `Escape` / `Delete` | C / AC |

## 테스트 실행

Node.js만 있으면 됩니다. (별도 패키지 설치 없음)

```bash
node test.js
```

통과하면 `N passed, 0 failed`가 출력되고 종료 코드는 `0`입니다.

주요 검증 항목:
- `2+3=5`
- `5×3=` 후 `=` 다시 → `45`
- `0.1+0.2=0.3` (부동소수점 오차 없음)
- `9÷0=Error`
- `50%=0.5`
- `1234567` → `1,234,567`
- `±` 토글, `C` vs `AC`

## GitHub Pages로 공개하기

1. GitHub 저장소 **Settings → Pages**로 이동합니다.
2. **Source**를 **Deploy from a branch**로 선택합니다.
3. Branch를 `main`(또는 배포할 브랜치), 폴더를 `/ (root)`로 두고 **Save**합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 계산기를 볼 수 있습니다.

루트에 `index.html`이 있으므로 추가 설정 없이 Pages에 올리면 됩니다. 3D 모드는 같은 주소 뒤에 `3d.html`을 붙이면 됩니다.
