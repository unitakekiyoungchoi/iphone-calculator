# iPhone 스타일 계산기

브라우저에서 동작하는 **iOS 계산기** 스타일의 작은 정적 웹 프로젝트입니다.  
검은 배경, 둥근 버튼, 주황색 연산자(선택 시 흰/주황 반전), 넓은 `0` 버튼, iOS와 비슷한 계산 규칙(×÷가 +−보다 우선, `=` 반복, `%` / `±`, 9자리 제한, 천 단위 쉼표, 0으로 나누면 Error 등)을 그대로 구현했습니다.

빌드 도구나 CDN 의존성은 없습니다. `index.html`을 더블클릭하면 오프라인에서도 바로 열립니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지 구조 |
| `styles.css` | 화면 스타일 |
| `calculator.js` | 계산 로직 (브라우저·Node 공용) |
| `app.js` | 버튼·키보드·스와이프 UI 연결 |
| `test.js` | Node로 실행하는 자동 테스트 |

## 사용 방법

1. 저장소를 클론하거나 파일을 받은 뒤
2. **`index.html`을 더블클릭**하거나, 브라우저로 해당 파일을 엽니다.

데스크톱에서는 휴대폰 프레임으로 보이고, 좁은 화면(모바일)에서는 전체 화면으로 채워집니다.

### 키보드 지원

| 키 | 동작 |
|----|------|
| `0`–`9`, `.` | 숫자 입력 |
| `+` `-` `*` `/` | 연산 |
| `Enter` 또는 `=` | 결과 |
| `%` | 퍼센트 |
| `Backspace` | 한 자리 삭제 (디스플레이 스와이프도 동일) |
| `Escape` / `Delete` | C / AC |

## 테스트 실행

Node.js만 있으면 됩니다. (별도 패키지 설치 없음)

```bash
node test.js
```

통과하면 `N passed, 0 failed`가 출력되고 종료 코드는 `0`입니다.

주요 검증 항목:
- `2+3=5`
- `5×3=` 후 `=` 다시 → `45`
- `0.1+0.2=0.3` (부동소수점 오차 없음)
- `9÷0=Error`
- `50%=0.5`
- `1234567` → `1,234,567`
- `±` 토글, `C` vs `AC`

## GitHub Pages로 공개하기

1. GitHub 저장소 **Settings → Pages**로 이동합니다.
2. **Source**를 **Deploy from a branch**로 선택합니다.
3. Branch를 `main`(또는 배포할 브랜치), 폴더를 `/ (root)`로 두고 **Save**합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 계산기를 볼 수 있습니다.

루트에 `index.html`이 있으므로 추가 설정 없이 Pages에 올리면 됩니다.
